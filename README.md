# customers-api

Customer management API (CDK v1: Elasticsearch, DynamoDB, Lambdas). Archived snapshot, as-is.

This tree is a **new public commit** with no git history. The original private archive is `eulertools/customers-api-archive`.

AWS account, VPC, subnet, security-group, hosted-zone, and ACM certificate ids were **replaced with placeholders**.

No contract deployments recorded in this repo.

## What was built (EN)

AWS CDK TypeScript project for a customer management API: Elasticsearch, Lambda authorizers, REST endpoints, DynamoDB, and a CodePipeline. Environment-specific configs for development and production.

## Qué se construyó (ES)
